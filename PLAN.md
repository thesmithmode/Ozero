# Текущий план Ozero

Документ описывает направления дальнейшей работы, а не историю выполненных изменений. Текущее устройство приложения — [архитектура](docs/architecture.md), подготовка APK — [сборка](docs/build.md).

## Состояние

Подключены ByeDPI, WARP/AmneziaWG, FPTN, URnetwork, MasterDNS и sing-box. Разработка ведётся в `dev`; `main` используется для выпуска APK. Исторические статусы веток и blocked-задачи из мая не определяют текущее состояние модулей.

## Следующие небольшие изменения

- Согласовать идентичность native-артефактов с wrapper sources: сначала проверить фактический FPTN asset, затем отдельно менять сборку и lock с Android ARM64-проверкой.
- Согласовать release assets со встроенным updater: он ожидает Ed25519 `.apk.sig`, тогда как workflow создаёт SHA256 и опциональную GPG `.asc`.
- Разобрать ограничение auto FPTN первыми четырьмя серверами: решить, является ли оно продуктовым пределом или нужен ограниченный бюджетом обход остальных кандидатов.
- Обновления CI actions переносить в `dev` отдельно от миграции Kotlin/Coroutines/AGP/Hilt/Gradle.
- Robolectric обновлять вместе с offline Android runtime dependencies и проверкой существующих тестов.

Работающий runtime остаётся исходной точкой. Изменения поведения требуют отдельной задачи, проверки причин и подтверждения отсутствия регрессий.
